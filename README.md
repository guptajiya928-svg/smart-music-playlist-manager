# Smart Music Playlist Manager with Smart Shuffle+

A C++17 console-based project that makes music playlist management smarter using *Data Structures, Algorithms, and OOP*.

##  Features

* Add, delete, and search songs
* Duplicate song detection
* Smart Shuffle+ based on mood, genre, and artist similarity
* Undo/Redo functionality
*  Recently played song history
*  Mood-based song selection
*  Generate playlists based on target listening duration
* Export playlist data to CSV

##  Concepts Used

* Doubly Linked List
* Stack
* Hash Map / Hash Set
* Graph
* Priority Queue
* Greedy Algorithm
* Dynamic Programming
* Object-Oriented Programming

##  Technologies

**Language:**C++
**Standard:* C++17
**Interface:* Console-Based Application
